This directory is intended to hold bundled fonts for the project.

License and bundling note:
- Do NOT add a font file here unless you have the right to redistribute it.
- Recommended open-source emoji fonts:
  - "Noto Color Emoji" (SIL OPEN FONT LICENSE?) - check licensing before bundling
  - "Symbola" (contains wide unicode coverage) - check license
  - Consider including a small custom TTF that contains only required glyphs.

If you want me to add a specific permissively-licensed font, paste the font filename or a URL and I will add it and wire it up.
